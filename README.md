# 🏦 Banking System

## 📌 Project Overview

The **Banking System** is a console-based Java application designed to simulate basic banking operations. The application allows users to create and manage bank accounts, deposit money, withdraw money, check account balances, and view account details through a simple command-line interface.

This project is developed using **Core Java** and demonstrates important **Object-Oriented Programming (OOP)** concepts along with the Java Collections Framework.

## 🎯 Objectives

* To develop a simple console-based banking application.
* To understand and implement Java OOP concepts.
* To manage multiple bank accounts efficiently.
* To perform basic banking transactions.
* To gain practical experience with `ArrayList` and user input handling.

## ✨ Features

* 🏦 Create a new bank account
* 💰 Deposit money
* 💸 Withdraw money
* 📊 Check account balance
* 👤 View account details
* 🔍 Search for an account
* 📋 Manage multiple accounts
* 🚪 Exit the application

## 🔄 Application Workflow

1. Start the application.
2. Display the banking menu.
3. Select an operation.
4. Create an account or enter an existing account number.
5. Perform deposit, withdrawal, or balance-checking operations.
6. Display the updated account information.
7. Continue performing operations or exit the application.

